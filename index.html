影像评测简历 · 文字风格对照报告

对象：韦安瑞　｜　对照：AI 初稿文字版 vs 本人修订版　｜　2026-09-17

一、说明

本报告单独整理「AI 发给你的文字版」与「你改完发回的文字版」的逐条差异，便于你点评并沉淀成后续写简历的固定规矩。

对照范围：个人优势、传音/联想/ODM 项目角色与表述、天珑工作经历相关用词。技能清单、Agent、米家/带教、耀皮、教育等你基本未改的大块，不纳入本表细项。

二、风格差异总括

AI 初稿容易堆「负责 / 协同 / 闭环 / 侧 / 贯通」和解释性长句；你的修订更偏「具体动词 + 去掉套话 + 把角色和进度说清楚」。

三、逐条对照（共 15 点）

1. 「光源环境」→「光源环境搭建」

AI偏名词堆砌。
你补上「搭建」，动作更完整，像人在说自己干什么。

2. 「很在意提效」→「注重提效」

AI「很在意」带一点口语夸张。
你「注重」更稳，更像简历用词。

3. 「看到…就想拆步骤…」→「遇到…会优先拆步骤…并做成 Skill」

AI「就想」像自我鸡汤。
你「遇到…会优先…并做成」是完整因果句，语气更实。

4. 「主责 AE/AWB」→「主要 AE/AWB」

AI「主责」偏职场黑话。
你「主要」更口语、更好懂。

5. 「评测进度与跨部门协同」→「评测进度统筹与跨部门协同」

你加了「统筹」，把「管进度」说清楚，不只是「协同」这种虚词。

6. 「深棕肤色影响效果」→「深棕肤色影像效果」

「影响效果」像笔误/机翻感；「影像效果」才是行内说法。

7. 删掉「对 AE/AWB 模块结果与进度负责」

AI爱在句尾再盖一章「负责」。
你认为角色行已经够了，避免套话重复。

8. AWB 结尾：「提报并跟踪至闭环」→「不同模式色彩一致性判断」

AI爱用「闭环」万能词。
你改成具体判断动作，更像测试人写的。
后续高级审阅建议再收成「以及不同模式的色彩一致性」，已按你确认落地。

9. 联想角色：「异地测试统筹」→「异地测试进度统筹」

同第 5 点：强调「进度」，不只「统筹」两个空字。

10. 删掉联想「偏色接受度比手机更高…」整条

AI写得像面试讲稿/科普。
你判断不适合放项目经历，或语气不像你，直接去掉。

11. ODM 角色：「影像评测支持」→「影像评测 SE」

AI偏保守（避免 SE 抬头）。
你按真实分工改成 SE，标题更干脆。

12. 「影像测试与验收问题支持」→「影像测试与问题验收」

「支持」偏虚；「问题验收」是具体交付，更像人话。

13. 「复用传音侧经验」→「复用传音项目经验」

「侧」是 AI 常挂的模板词；你改成「项目」，更自然。

14. 「贯通用例—测试—…」→「确定用例—测试—…」

「贯通」偏书面/AI；「确定用例」与传音推进口径一致，也更具体。

15. 「评测进度协同」→「评测进度统筹」

同第 5、9 点：你偏好「统筹」而不是空的「协同」。

四、可固定成规矩的写法（建议）

  1. 动作写全：少写光秃名词，多写「搭建 / 确定 / 提报 / 回归 / 统筹」等可执行动词。
  2. 少用万能词：慎用「闭环、协同、侧、贯通、主责、负责（句尾重复盖章）」。
  3. 进度说清楚：需要体现管理时，优先「评测进度统筹」，不要只写「协同」。
  4. 角色与正文一致：抬头是 SE / 助理，正文用「负责 / 统筹」或「助理」，避免「参与」把抬头写虚。
  5. 解释性长句能删就删：面试可讲的细节，不必硬塞进项目经历。
  6. 提效用「注重 / 遇到…会优先…」，少用「很在意 / 就想」。

五、使用说明

请你按 1–15 点做评价（保留 / 修正 / 作废）。评完后可把「要固定成规矩」的几条标出来，后续写简历会按你的规矩执行。
